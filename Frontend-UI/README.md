# TabWink React UI

## Open and run in VS Code

1. Extract this folder.
2. In VS Code, choose **File > Open Folder** and open `tabwink-react-ui`.
3. Open a new terminal. Confirm the path ends in `tabwink-react-ui`.
4. Because PowerShell blocks `npm.ps1` on the current device, use:

```powershell
npm.cmd install
npm.cmd run dev
```

5. Open the local address shown in the terminal, normally `http://localhost:5173`.

The current bot reply is a frontend demo placeholder. Replace it with a `fetch()` call after the Python API endpoint and response format are available.
